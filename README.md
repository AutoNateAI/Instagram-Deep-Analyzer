# Instagram Deep Analyzer

An interactive dashboard for analyzing Instagram data with a focus on comment volume and market attention metrics. This tool helps you understand audience engagement patterns and generates meme prompts based on data insights.

## Features

- **Data Upload**: Simply upload your Instagram JSON data file
- **Interactive Dashboard**: Visual analysis of Instagram engagement metrics
- **Comment Volume Analysis**: Focus on comments as a key engagement metric
- **Audience Focus Insights**: Understand what your audience is paying attention to
- **Meme Prompt Generator**: 12 AI-generated meme prompts for your content strategy
  - 5 multi-panel storytelling memes with conversation bubbles
  - 7 single-panel memes with insightful captions
- **PDF Export**: Export the full report for offline sharing

## How to Use

1. Visit the [Instagram Deep Analyzer](https://autonateai.github.io/Instagram-Deep-Analyzer/) webpage
2. Upload your Instagram JSON data file
3. Analyze the interactive visualizations and metrics
4. View suggested meme prompts based on your data
5. Export a PDF report if needed

## Local Development

To run this project locally:

1. Clone the repository:
   ```
   git clone https://github.com/AutoNateAI/Instagram-Deep-Analyzer.git
   ```

2. Open the project folder:
   ```
   cd Instagram-Deep-Analyzer
   ```

3. Open `index.html` in your browser or use a local server

## Data Privacy

This application processes all data in your browser. No data is sent to any server, ensuring your Instagram data remains private and secure.

## Deployment

This project is automatically deployed to GitHub Pages whenever changes are pushed to the main branch using GitHub Actions.

## Technologies Used

- HTML5/CSS3
- JavaScript (ES6+)
- Chart.js for data visualization
- Bootstrap for UI components
- html2pdf.js for PDF export
